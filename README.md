# IAM Portfolio Character Assets

Static asset host for the transparent WebP frame sequence used by
`CharacterFrameSequence.tsx` in the IAM Portfolio Framer site.

- `frames/frame_0001.webp` … `frames/frame_0121.webp` — 121 transparent
  WebP frames (1284×716) of the character transformation animation.
- `frames-manifest.json` — frame metadata.

Served via GitHub Pages. Not a web app — just static assets.
